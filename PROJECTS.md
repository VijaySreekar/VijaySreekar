## Featured products

### [Orbit ERP](https://orbit-erp-psi.vercel.app/)

A separate portfolio edition of a modular ERP developed in collaboration with Manikata Tej. **Demo login** opens an administrator workspace with editable fictional data, including sales, purchasing, inventory, finance, HR, payroll and project workflows. It uses Next.js, React, TypeScript, FastAPI, SQLAlchemy and PostgreSQL. The portfolio environment is separate from the original business system; its source is private.

[Open the live demo](https://orbit-erp-psi.vercel.app/). The free backend may take about a minute to wake, and demo changes are shared.

### [Wandrix](https://github.com/VijaySreekar/Wandrix-Live)

An AI travel planner with a conversation beside a structured, editable trip board. It saves trip drafts across sessions, keeps brochure snapshots as versions of a trip and exports them as PDFs. The public implementation uses Next.js, React, TypeScript, FastAPI, LangGraph, PostgreSQL, SQLAlchemy and Alembic.

[Visit Wandrix](https://www.wandrix.app/) · [Explore the code and architecture](https://github.com/VijaySreekar/Wandrix-Live#architecture)

## Other applications

**[Spotify Insights](https://github.com/VijaySreekar/StreamLitSpotifyInsights)** — A shared Streamlit application co-built with [GanapathiThota](https://github.com/GanapathiThota). It analyses uploaded listening-history exports by artist, track, day and hour using Python and pandas; fictional sample data is available. [Setup and sample data](https://github.com/VijaySreekar/StreamLitSpotifyInsights#run-locally).

**[Treakers](https://github.com/VijaySreekar/treakers-demo)** — A PHP sneaker storefront and admin dashboard built by Team 27 at Aston University. The separate demo uses seeded SQLite data rather than a production shop. [Live demo](https://treakers-demo.vercel.app/) · [Original team repository](https://github.com/VijaySreekar/Team-27) · [Screenshots](https://github.com/VijaySreekar/treakers-demo#screenshots).

**[Alarm App](https://github.com/VijaySreekar/AlarmApp)** — A React Native/Expo prototype with locally saved alarms, local notifications and a five-minute snooze. Repeat scheduling and dependable background delivery remain prototype limitations.

**PulseCheck** — A local Go HTTP monitoring project. It probes configured endpoints concurrently with per-request timeouts and reports status, latency and errors through a JSON endpoint. It has automated tests and a Docker build; the source is not public yet.
